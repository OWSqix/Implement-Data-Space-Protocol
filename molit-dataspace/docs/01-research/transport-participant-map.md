## 1. 목적과 범위

- **(목적)** 교통·물류 데이터의 공급자와 제출 경로를 식별하고 참가자 범위의 설계 근거를 제공
- **(질문)** 누가 어떤 데이터를 어느 수신처에 어떤 근거와 주기로 제출하며, 직접 제출과 2차 재배포는 어떻게 구분되는가
- **(포함 범위)** 14개 공급측 참가자군, 공개 근거로 식별한 66개 직접 제출·전달 경로, 8개 2차 복제유통, 직접 중복과 공통 식별정보의 반복
- **(제외 범위)** 특정 회사의 전체 인터페이스 수, 회사별 절감액, 비공개 협약·API 명세, 법정 제출을 대행하는 데이터 스페이스 구현
- **(판정 기준)** 서로 다른 발신자·수신자·업무절차를 직접 경로 1개로 산정하고, 같은 수신처의 웹·엑셀·API 선택지는 1개로 산정

페이지 개념이 없는 웹 자료의 페이지는 출처 표에서 해당 없음으로 기록한다. 발행일을 찾지 못한 자료는 발행일 미확인으로 유지한다. 조사 입력의 외부 링크 확인일은 원문과 같은 2026-08-02다.

상태 표기는 다음 기준을 따른다.

- **Verified:** 1차 출처 또는 재현 가능한 문서 관찰에서 직접 확인
- **Inferred:** 확인 사실을 대조해 도출한 해석
- **Unverified:** 필요한 문서·명세·시험을 확보하지 못해 판정 불가
- **Decision:** 이 조사에 따라 프로젝트가 채택하거나 요청하는 선택

## 2. 현재 판정

### 2.1 경로 수 판정

- **(Verified)** 공급측 참가자군은 14개이고 직접 제출·전달 경로는 66개임
  - **(근거)** 군별 경로 수는 버스 8, 철도 11, 택시 7, 화물·물류 8, PM·공유 4, MaaS·내비 3, 자율주행·UAM 8, 카드·정산 1, 인프라 2, 연구·공공 2, 자동차 3, 주차·충전 4, 항공 2, 해운·항만 3임 — SRC-TPM-001
  - **(조건)** 66개는 공개 근거로 식별한 주요 업무경로 유형이며 전국 사업자별 접속 수의 합계가 아님
- **(Verified)** 66개는 법정·승인통계 정기·사건형 41개, 법정 요청 시 10개, 계약·보조금·업무협약·운영협약 14개, 일반 제출의무가 확인되지 않은 TIMS 1개로 구성됨 — SRC-TPM-001
- **(Verified)** 후속 복제유통 8개는 원 공급자의 추가 제출이 아니므로 66개에서 제외됨 — SRC-TPM-001

### 2.2 중복 판정

- **(Verified)** 공개 근거로 동일정보의 직접 이중 경로가 확인된 대상은 버스 사업계획 변경과 철도 안전투자 공시임 — B01·B02, R05·R06
- **(Inferred)** 반복 부담은 동일 파일보다 사업자·차량·노선·운전자 식별정보를 별도 절차에서 다시 기재하는 형태가 넓음 — 5.2절
- **(Unverified)** 관청용 버스 신청서와 조합 통지 전문이 바이트 단위로 같은지는 문서 미확인임
- **(Unverified)** 특정 회사의 실제 계정·파일·API 수와 월간 수정·재제출 횟수가 없어 절감액은 산정 불가함

### 2.3 수요와 참가자 판정

- **(Verified)** 수요 주체에는 MaaS·내비게이션, 보험, 연구기관, 지방자치단체, 정산사업자, 상권·광고 분석과 교통약자 서비스가 포함됨 — 6절
- **(Inferred)** 같은 참가자 범주에 공급자·수신자·구매자·분석자 역할이 함께 나타남 — 9.1절
- **(Inferred)** 14개 공급측 참가자군과 66개 경로만으로 참가자 범위를 정하면 수요자와 상호성 요구가 누락됨
- **(Decision)** 운수 분야 제출자 중심의 참가자 전제를 폐기하고 수요 역할을 참가자 범위에 포함 — 10.1절

- **(Decision)** 참가자 조사 항목에 원하는 데이터, 사용 목적, 갱신주기, 접근조건, 구매·요청·거부·호출·재사용과 환류 결과를 포함

- **(Unverified)** 수요 원장에 등록할 기관 전수, 실제 호출량과 추가 제공 의사는 문서 미확인임 — OPEN-TPM-05·12·13
