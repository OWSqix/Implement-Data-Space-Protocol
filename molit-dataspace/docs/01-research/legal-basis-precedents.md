## 1. 목적과 범위

- **(목적)** 국토교통 데이터 스페이스를 세우는 법적 근거와 자료 등록·제출·제공·연계 의무를 부과할 수 있는 현행 조문의 식별
- **(질문)** 현행법은 어떤 시스템과 기능을 직접 뒷받침하며, 어느 기관과 민간 주체에 어떤 자료 의무를 부과하는가
- **(포함 범위)** 국토교통 분야와 범정부·타 부처의 시스템 선례 31개, 의무 부과 가능 조문, 제재 결합 제도군, 후행 입법, 연합형 적용 문제
- **(제외 범위)** 시스템 경유 제출의 법정 제출 간주와 효력 부여, 개별 데이터의 적법한 제3자 제공 판정, 법률안 문안과 법률자문
- **(관련 문서)** 간주와 효력 부여는 mandate-and-deeming-precedents.md에서 다루며, 이 문서에서는 중복 서술하지 않음
- **(판정 기준)** 직접 근거는 법률이 시스템 또는 그 기능을 명시한 경우, 간접 근거는 일반 사업권한·지원조항·직제·훈령만 있는 경우
- **(조사 기준)** 국가법령정보센터 현행 원문을 우선하고, 입력 원문이 제시한 외부 자료의 확인일 2026-08-02를 유지함 — SRC-LBP-001

상태는 1차 출처에서 직접 확인한 사실을 Verified, 확인 사실에서 도출한 해석을 Inferred로 표기한다. 문서나 현행성을 확보하지 못한 항목은 Unverified, 프로젝트의 선택은 Decision으로 표기한다.

## 2. 현재 판정

### 2.1 핵심 판정

- **(판정)** 조사단위는 31개이며, 직접 근거 21개, 간접 근거 7개, 실체적 설치법 미확인 3개로 구분됨. 상태: Verified — SRC-LBP-001
- **(판정)** 등록·제출·제공·연계 의무를 부과할 수 있는 조문은 13개 법률의 최소 31개 조문으로 확인됨. 상태: Verified — 4절, SRC-LBP-002~SRC-LBP-014
- **(판정)** 일반 민간 참가자 전체에 상시 데이터 등록·교환을 강제하는 범용 선례는 없었다. 상태: Inferred — 조사 범위 31개, SRC-LBP-001
  - **(예외)** 스마트농업법 제21조는 관련 법인·단체까지 포함하지만, 플랫폼 “구축에 필요한 자료”로 범위가 한정되고 제재가 없음. 상태: Verified — SRC-LBP-014
- **(판정)** 제재까지 결합된 대표 제도군은 RTMS, KISCON 공사대장, FMS 법정보고, 금융 마이데이터임. 상태: Verified — 5절
- **(판정)** 나머지 대부분은 “정당한 사유가 없으면 협조”에 그치고, 불응 자체의 과태료·형벌이 없음. 상태: Verified — 4절, SRC-LBP-002~SRC-LBP-014
- **(판정)** 교통데이터에는 「국가통합교통체계효율화법」 제17조의2가 가장 직접적인 현행 근거임. 상태: Verified — SRC-LBP-002
  - **(한계)** 국토·공간·건축·부동산·시설물·자동차를 포괄하는 연합형 데이터 스페이스, 민간 영리기업의 참여·제출, 전담운영기관 지정, 참가자 간 교환중개와 안정적 운영비까지는 포섭하지 못함. 상태: Inferred
- **(판정)** 2027~2030년 자발적 연구개발 실증은 기존 조항과 예산을 조합할 수 있으나, 종료 후 상시운영과 지자체·공기업 의무화를 위해서는 법률 개정이 필요함. 상태: Inferred
  - **(근거)** 작성 기준 2026-08-02, 7절, SRC-LBP-002·003·010·016·017

### 2.2 판정의 한계

- **(한계)** 21개·7개·3개의 총계는 원문에 있으나, 31개 조사단위별 근거 유형 매핑표는 없음. 상태: Unverified — OPEN-LBP-01
- **(한계)** 자동차365와 산업데이터 플랫폼의 직접·간접 경계는 원문 기준만으로 판정 불가. 상태: Unverified — OPEN-LBP-01
- **(한계)** 이 조사는 법령·제도 사실조사이며 법률자문이 아님. 신규 조문의 체계상 위치와 개별 데이터 제공의 적법성은 관계 기관의 공식 확인 대상임.

### 3.3 근거 유형의 대표 경계

- **(직접 근거)** 교통빅데이터플랫폼은 법 제17조의2가 구축·운영, 기관 데이터베이스 활용과 자료제출 협조를 명시함. 상태: Verified — SRC-LBP-002
- **(직접 근거)** 스마트농업 데이터 플랫폼은 법 제13조가 구축·운영과 다른 시스템 연계를 명시함. 상태: Verified — SRC-LBP-014
- **(간접 근거)** 국토교통 데이터 통합채널은 공공데이터법·데이터기반행정법·데이터산업법과 부내 훈령만 확인됨. 상태: Verified — SRC-LBP-001, SRC-LBP-016
- **(간접 근거)** 보건의료 빅데이터 통합플랫폼은 플랫폼 설치조항 대신 연구기관의 자료요청·결합 권한을 기능상 근거로 사용함. 상태: Verified — SRC-LBP-013
- **(미확인)** FinDX 설치와 금융보안원 운영을 직접 정한 법률·고시를 확인하지 못함. 상태: Unverified — SRC-LBP-024, OPEN-LBP-07
- **(미확인)** 의료데이터 중심병원의 실체적 설치법·계속운영 재원조항을 확인하지 못함. 상태: Unverified — SRC-LBP-022, OPEN-LBP-08
- **(미확인)** 해양수산 빅데이터 거래소의 설치법과 2023년 이후 계속운영 예산·기금조항을 확인하지 못함. 상태: Unverified — SRC-LBP-023, OPEN-LBP-10

## 7. 단계별 입법 범위

### 7.1 2027~2030년 연구개발 실증

- **(판정)** 교통 데이터는 통합교통체계법 제17조·제17조의2, 공간정보는 국가공간정보 기본법 제24조 이하를 조합할 수 있음. 상태: Inferred — SRC-LBP-002, SRC-LBP-003
- **(판정)** 공공기관 간 실증은 데이터기반행정법, 플랫폼 기술 연구는 데이터산업법·산업디지털전환법을 조합할 수 있음. 상태: Inferred — SRC-LBP-010, SRC-LBP-016, SRC-LBP-017
- **(조건)** 이 조합은 연구개발 수행과 자발적 제공의 근거이며, 참가기관 전체의 가입·상시연계를 강제하는 근거가 아니다.

### 7.2 고시·훈령의 한계

- **(가능 범위)** 국토교통부 내부 조직·담당부서, 시스템 명칭·기술구조·API·메타데이터 표준, 위임된 절차·서식과 자발적 참가약정
- **(불가 범위)** 지자체·공기업·민간의 새 일반 등록·제출 의무, 영리기업 강제참가, 비회원 제재와 운영기관의 조사·명령·제재 권한
- **(불가 범위)** 다른 목적으로 수집한 개인정보·영업비밀의 제공 허용과 법률상 비공개·목적제한의 해제

국민의 권리를 제한하거나 의무를 부과하는 규제는 법률에 근거해야 한다. 고시는 구체적 위임 범위의 기술적·경미한 사항을 정할 수 있다. 상태: Verified — SRC-LBP-015.

### 7.3 종료 후 상시운영

- **(판정)** 교통 중심이면 제17조의2 개정이 우선 검토 경로이나, 국토교통 전 분야를 포괄하면 새 조문 또는 별도 장이 필요함. 상태: Inferred — SRC-LBP-002
- **(한계)** 국토교통 전 분야를 한 번에 포섭하는 옴니버스 조항은 확인되지 않음. 상태: Unverified — SRC-LBP-001
- **(미확인)** 제17조의2는 일부 지자체·지방공기업의 자료 협조를 이미 규정하지만, 원문은 종료 후 지자체·공기업 의무화에 법률 개정이 필요하다고 판정함. 두 서술의 관계는 문서 미확인. 상태: Unverified — OPEN-LBP-17
- **(결정 요청)** 제17조의2 개정과 범분야 별도 장 중 입법 경로를 법무 검토 뒤 선택할 필요. 상태: Decision — OPEN-LBP-14

최소 입법요소는 다음과 같다. 상태: Inferred — SRC-LBP-001.

1. 국토교통 데이터 스페이스와 연합형 교환·중개의 정의
2. 국토교통부장관의 구축·운영 의무 또는 권한
3. 전담운영기관의 지정·취소·업무범위와 운영비 출연·보조
4. 중앙행정기관·지자체·공공기관·지방공기업 중 의무 참가자의 범위
5. 민간의 원칙적 자율참여와 규제업종별 필수데이터의 별도 의무
6. 메타데이터 등록, 커넥터 연결과 실제 제공을 구분한 의무
7. 자료범위·제출주기·거절사유와 분리가능 정보 제공
8. 비용·유상거래·표준계약·차별금지와 분쟁조정
9. 개인정보·가명정보·위치정보·영업비밀·국가보안·저작권 보호
10. 로그·감사·사고통보·책임배분과 운영기관의 비밀유지
11. 단계적 시정요구·평가·공표와 필요한 경우에만 과태료

## 8. 연합형 데이터 스페이스의 조문 적용

### 8.1 포섭 가능한 기능

- **(관찰)** 통합교통체계법 제17조의2는 각 기관 데이터베이스·시스템의 활용을 명시하고, 시행령은 데이터 송수신·연동을 규정함. 상태: Verified — SRC-LBP-002
- **(관찰)** 데이터기반행정법은 기관 간 요청·제공·전자적 연계·공동활용을 명시함. 상태: Verified — SRC-LBP-010
- **(관찰)** 전자정부법 공동이용센터는 원천기관이 자료를 유지한 상태의 조회·전달 기능을 가짐. 상태: Verified — SRC-LBP-011
- **(관찰)** 산업디지털전환법은 플랫폼 간 상호호환·연계와 데이터 공유·거래를 정책대상으로 둠. 상태: Verified — SRC-LBP-017
- **(관찰)** NDI는 공공·민간 데이터 통합검색·카탈로그·상호운용·인증·데이터주권을 갖춘 시범 인프라로 설명됨. 상태: Verified — SRC-LBP-041, SRC-LBP-042
- **(관찰)** 데이터안심구역은 클라우드 기반 가상구역을 인정함. 상태: Verified — SRC-LBP-043
- **(판정)** 원천데이터가 중앙 저장소로 이동하지 않는다는 이유만으로 제17조의2 적용이 배제되지는 않음. 상태: Inferred

- 참가자 인증·커넥터 인증·접근정책을 집행하는 중개자
- 데이터 제공자가 목적·기간·재제공 조건을 기계적으로 통제하는 구조
- 참가자 간 유상거래·정산·비차별 접속
- 원천기관에 남은 데이터에 대한 원격 연산
- 교환 실패·오류·침해사고의 다자 책임배분

제17조의2는 플랫폼 목적을 “연계·융합 분석”으로 한정하고, 시행령은 교통 연구·정책수립 자료를 중심으로 한다. 산업적 재사용과 참가자 상호 거래는 명문 목적이 아니다. 개인정보는 제17조의2제3항에 따라 플랫폼 수집·관리 대상에서 제외된다. 상태: Verified — SRC-LBP-002.

### 8.3 별도 법적 판정 대상

- **(판정 대상)** 원격조회, API 응답, 연산결과 반출과 제3자 접근권 부여가 법률상 제공 또는 처리인지 여부
  - **(조건)** 개인정보·신용정보·위치정보·영업비밀별로 기술방식과 권한구조를 대조해야 판정 가능
- **(판정)** 현행 조문은 연합형 기술을 금지하지 않지만, 연합형 거버넌스와 참가자 간 교환관계를 규율하지 않음. 상태: Inferred
- **(입법 검토)** 원천기관 보유 상태의 전자적 접근·전송·연산 중개를 정의하고, 운영기관과 참가자의 권한·책임을 구분할 필요. 상태: Inferred
